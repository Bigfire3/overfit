# overfit

Ein minimalistischer KI-Fitness-Coach. Schwarz-weiß, ohne Werbung, mit deinem eigenen API-Key.

## Entwicklung

```bash
npm install
npx expo start          # iOS/Android über Expo, Web mit "w"
npm run check           # Typecheck, Lint, Tests
```

Produktentscheidungen und Konventionen: siehe [CLAUDE.md](CLAUDE.md).
